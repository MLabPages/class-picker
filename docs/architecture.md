# Architecture

## 概要

Class Picker は `index.html` だけで動く静的 Web アプリです。GitHub Pages などの HTTPS 配信を前提に、教員が参加コードを作り、学生が同じコードの抽選に参加します。

## 主な流れ

1. URL の `room` / `code`、または `localStorage` から参加コードを決める。
2. 参加コードに対応する QR コードと共有 URL を表示する。
3. 学生が名前・属性などを入力して、同じ参加コードの待機状態へ入る。
4. 抽選処理がグループと配置を決め、必要に応じて Firebase Realtime Database で残数・設定を共有する。
5. 左上の複数回タップから管理画面を開き、設定・リセット・参加コード切替を行う。

## データ境界

- Firebase 設定は `index.html` に埋め込まれたクライアント設定である。
- Firebase を使う場合は参加コード単位で一時データと残数を管理し、管理画面からリセットする。
- Firebase が使えない場合は端末内の保存にフォールバックするため、複数端末での厳密な残数共有はできない。
- 管理コードはクライアント側の画面開示に使う値であり、公開サービスの強い認証・権限管理とは分けて考える。
