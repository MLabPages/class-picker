# 2026-10-13: 管理コードを数字8桁へ簡略化

授業中にスマホで長い英数字を入力する負担を減らすため、教員管理コードを暗号学的乱数による数字8桁に変更した。入力欄に `inputmode="numeric"` と8桁の案内を追加し、新規作成でも数字8桁を発行する。

既存教員には、短いコードのハッシュから元の教員IDへ結び付くprivateなレコードを追加した。新しいコードと従来のCP-形式のコードは同じ教員として照合する。関連先が不正・不存在・無効の場合や、関連先も別の教員への関連付けになっている場合は拒否する。元の教員を無効化すると両コードと確認済みセッションが無効になる。既存のIP単位の照合頻度制限と8時間の確認期間は維持する。
