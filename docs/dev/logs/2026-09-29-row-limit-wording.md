# 1列あたりのグループ数上限の説明

日付: 2026-09-29

## 目的

- 「数字のみ版は空欄でも10」という表示が、常に10組並ぶように読めるため、上限であることと空欄時の扱いを正しく示す。

## 変更

- ラベルを「1列あたりのグループ数上限」にし、入力欄の例は表示方式に合わせて「空欄なら10」（数字のみ）または「空欄なら自動」（列番号版）とした。
- 欄の下に、空欄時の扱いと、今の設定で1列に並ぶ組数の最大を表示するようにした。
- 列別上限の例文と管理画面の説明で、「行数上限」を「1列あたりのグループ数上限」にそろえた。
- README と現在状態を更新した。計算の動作は変えていない。

## 確認

- JavaScript構文確認（`node --check`）と `git diff --check`: 成功。
- Firebase設定を空にした一時コピーをアプリ内ブラウザーで表示し、管理画面で確認した。
  - 数字のみ・181人・5列・上限10：「上限まで埋める」で最大10組、「そろえる」で最大9組と表示された。
  - 上限を空欄にすると入力欄に「空欄なら10」と出て、計算は上限10のときと同じだった。上限8では40組に減り、最大8組と表示された。
  - 列番号版で空欄にすると「空欄なら自動」と出て、最大9組と表示された。果物版では「果物版では使いません。」と出た。
