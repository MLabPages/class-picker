# 余り人数の配分方式を選択可能にする

日付: 2026-09-29

## 目的

- 今回の方式（181人・4人基準なら44組×4人と1組×5人）に加え、従来の均等配分も選べるようにする。

## 変更

- 管理画面に余り人数の配分選択を追加し、今回の方式を初期値にした。
- 従来方式では必要組数を維持し、181人・4人基準なら46組（4人組43、3人組3）に分ける。
- どちらの方式でも配置枠が必要数に足りないときは、配置上限を優先する既存動作を保つ。
- 配分方式の変更時は抽選状態をリセットする。
