# 人数が少ない組から割り当てる

日付: 2026-09-29

## 目的

- 欠席者が次回に抽選したとき、人数の少ない組に入るようにする。
- 当日の欠席で空いた枠が一部の組に偏らないようにする。

## 変更

- Firebase 接続時の抽選で、抽選直前に `groupCounts`（男女均等モードでは `groupStats`）を読み、空きのある組のうち今の人数が少ない組から順にトランザクションを試すようにした。同じ人数の組どうしはランダム。
- 男女均等モードでは、性別の枠が空いている組、人数が少ない組、同じ性別が少ない組の順に優先する。
- 使わなくなった `shuffled` を削除した。
- 自動リセットの説明と、欠席者を次回に入れる手順を管理画面と README に追加した。

## 確認

- JavaScript構文確認（`node --check`）と `git diff --check`: 成功。
- Firebase の代わりに localStorage へ保存する偽データベースを検証用コピーに差し込み、アプリ内ブラウザーで端末を切り替えながら抽選した。共有Firebaseや本番ページには接続・書き込みしていない。
  - 定員22人（5組：4,4,4,5,5）で18人が抽選すると 3,4,3,4,4 人。後から4人が抽選すると、2人は3人の組へ、残り2人は定員5人の組へ入り、4,4,4,5,5 人になった。23人目は満員の案内が出た。
  - 男女均等モード（12人・3組）で男3人、女2人、男1人の順に抽選すると 2,2,2 人。後日抽選した女性は女性がいない組に入った。
  - 男性が多い場合（8人・2組で男5人）は、性別の枠が埋まったあと空いている組へ入り、その後の女性は人数の少ない組に入った。
- 本物の Firebase での同時抽選の負荷や、教室の実端末での確認は未実施。
