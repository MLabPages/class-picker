# 数字のみのグループ番号と余り人数

日付: 2026-09-29

## 目的

- A1形式に加え、グループ番号を1からの通し番号で表示できるようにする。
- 座席図に合わせ、1列に最大10グループを上から配置して次の列へ続ける。
- 181人・基準4人のとき、4人組44と5人組1の45グループにする。

## 変更

- 管理画面に「数字のみ」表示を追加した。数字のみでは列ごとに上から番号を振り、初期上限10グループで次の列へ折り返す。
- 余りが1人で配置枠に余裕がある場合、最後の1グループを基準人数より1人多くする。ほかの人数の余り方は従来の均等配分を維持する。
- README、現在状態、設計判断を更新した。

## 確認

- JavaScript構文確認: 成功。
- `git diff --check`: 成功。
- Firebase設定を空にした一時コピーをブラウザーで表示し、181人・4人基準・5列・各列10組の条件で番号1〜45、45番の上限5人、ほか44組の上限4人を確認した。
- 一時コピーでの表示確認のため、共有Firebaseや本番ページには接続・書き込みしていない。
